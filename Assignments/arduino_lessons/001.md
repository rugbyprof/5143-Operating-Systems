# **Arduino Lesson 1 – Blinking an LED**

**Student Handout**

This handout provides the essential steps to complete the “Blink an LED” activity using an Arduino. Follow each section in order. No prior hardware experience is required.

---

# **1. Objective**

You will build a simple circuit with an LED and write a program that makes the LED turn on and off at a regular interval.

---

# **2. Required Parts**

- Arduino Uno (or compatible board)
- USB cable for the board
- Breadboard (half-size is sufficient)
- 1 LED (any color)
- 1 resistor: **220 Ω or 330 Ω**
- 2–4 jumper wires (male-to-male)

---

# **3. Basic Concepts**

- Arduino **digital pins** can output either **HIGH (5V)** or **LOW (0V)**.
- An LED must be connected **through a resistor** to avoid damage.
- The LED has polarity:

  - **Long leg** = positive (anode)
  - **Short leg** = negative (cathode)

---

# **4. Circuit Assembly Steps**

Follow the steps exactly. If something does not work, recheck each connection.

### **4.1 Insert the LED**

1. Place the LED on the breadboard so each leg is in a **different row**.
2. Identify the **long leg (anode)** and **short leg (cathode)**.

### **4.2 Add the Resistor**

3. Insert one end of the resistor into the **same row as the LED’s long leg**.
4. Insert the other end of the resistor into a new row.

### **4.3 Connect the Arduino Pin**

5. Use a jumper wire from **Arduino pin 13** to the row containing the **free end of the resistor**.

### **4.4 Connect Ground**

6. Use another jumper wire from the **LED’s short leg row** to one of the Arduino **GND** pins.

### **4.5 Verify Connections**

7. Ensure the path is:
   **Pin 13 → Resistor → LED (long leg) → LED (short leg) → GND**.
8. Confirm nothing is connected directly between **5V and GND**.

---

# **5. Arduino IDE Setup**

1. Open the Arduino IDE.
2. Select **Tools → Board → Arduino Uno** (or the correct board).
3. Select **Tools → Port** and choose the port labeled “Arduino.”
4. Create a new sketch (**File → New**).

---

# **6. Upload the Blink Program**

### **6.1 Copy and paste this code:**

```cpp
const int LED_PIN = 13;

void setup() {
  pinMode(LED_PIN, OUTPUT);
}

void loop() {
  digitalWrite(LED_PIN, HIGH);
  delay(500);
  digitalWrite(LED_PIN, LOW);
  delay(500);
}
```

### **6.2 Upload**

5. Click **Verify** (✓).
6. Click **Upload** (→).
7. Observe the LED turning on and off.

---

# **7. Experiment**

Try the following modifications:

- Change the delay values (e.g., `delay(100)` or `delay(1000)`).
- Move the LED circuit to another digital pin (e.g., pin 8) and update `LED_PIN` in the code accordingly.

---

# **8. Troubleshooting**

- **LED never turns on**

  - Check LED orientation (long leg must go toward the resistor and Arduino pin).
  - Confirm GND wire is connected to a GND pin.
  - Ensure the resistor and LED are not placed in the same row.

- **Compilation errors**

  - Verify the code is copied exactly.
  - Ensure bracket pairs `{}` and semicolons `;` are intact.

---

# **End of Lesson 1**

Your LED should now be blinking. You will use this circuit and programming structure in the next lesson, where you’ll add a potentiometer to control behavior dynamically.
