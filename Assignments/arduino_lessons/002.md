# **Arduino Lesson 2 – Using a Potentiometer to Control an LED**

**Student Handout**

In this lesson, you will read an **analog input** from a potentiometer and use it to control the **blink speed** of an LED. This builds directly on Lesson 1.

---

# **1. Objective**

You will:

- Connect a **potentiometer** to an Arduino analog input pin.
- Read its value using `analogRead()`.
- Map that value to a delay time.
- Use the mapped value to change the LED’s blink speed.

---

# **2. Required Parts**

- Arduino Uno (or compatible)
- USB cable
- Breadboard
- 1 LED
- 1 Resistor (220 Ω or 330 Ω)
- 1 Potentiometer (any value between 5kΩ and 20kΩ works; common is **10kΩ**)
- 6–8 jumper wires (male-to-male)

You may reuse the LED circuit from Lesson 1.

---

# **3. Basic Concepts**

### **Potentiometer**

- Acts as a **variable resistor**.
- Arduino uses it as a **voltage divider** to measure a value between **0 and 5V**.
- The result of `analogRead(pin)` is a number from:

  - **0 (0V)**
  - **1023 (5V)**

### **Mapping the Value**

To convert the potentiometer reading into a useful range (like a blink delay), we use `map()`.

Example:

```text
0–1023  →  100–1000 milliseconds
```

---

# **4. Circuit Assembly Steps**

## **4.1 Keep Your LED Circuit**

Keep using the LED circuit from Lesson 1:

```
Digital Pin (e.g., 13) → Resistor → LED (long leg) → LED (short leg) → GND
```

## **4.2 Add the Potentiometer**

A standard potentiometer has **three pins**:

- **Left pin:** Connect to **5V**
- **Middle pin:** Connect to **A0**
- **Right pin:** Connect to **GND**

Follow these steps:

1. Insert the potentiometer into the breadboard so each pin sits in a different row.
2. Use a jumper to connect the **left pin** to **5V** on the Arduino.
3. Connect the **right pin** to **GND**.
4. Connect the **middle pin** to **analog pin A0**.

**Double-check:**

- Only the **middle pin** goes to A0.
- The two outer pins **must** go to 5V and GND.

# **5. Arduino IDE Setup**

1. Open the Arduino IDE.
2. Select the correct board and port under **Tools**.
3. Create a new sketch.

---

# **6. Upload the Program**

### **6.1 Copy and paste this code:**

```cpp
const int LED_PIN = 13;   // LED pin
const int POT_PIN = A0;   // Potentiometer middle pin

void setup() {
  pinMode(LED_PIN, OUTPUT);
}

void loop() {
  int potValue = analogRead(POT_PIN);   // Read 0–1023
  int delayTime = map(potValue, 0, 1023, 100, 1000); // Map to 100–1000 ms

  digitalWrite(LED_PIN, HIGH);
  delay(delayTime);

  digitalWrite(LED_PIN, LOW);
  delay(delayTime);
}
```

### **6.2 Upload**

4. Click **Verify** (✓).
5. Click **Upload** (→).
6. Turn the potentiometer knob and observe the blink speed change.

# **7. Experiment**

Try the following modifications:

- Change the `map()` output range (e.g., 20–500 ms).
- Make the potentiometer control **only the ON time** or **only the OFF time**.
- Print the potentiometer value:

```cpp
Serial.begin(9600);
Serial.println(potValue);
```

(Requires opening **Tools → Serial Monitor**.)

---

# **8. Troubleshooting**

- **Blink speed does not change**

  - Ensure the potentiometer’s _middle pin_ is connected to A0.
  - Verify the outer pins are connected to **5V** and **GND**.
  - Check for loose jumper wires.

- **LED does not blink**

  - Confirm the LED and resistor circuit from Lesson 1 is intact.
  - Verify `LED_PIN` matches the physical pin connection.

- **Uploading errors**

  - Check that the correct COM port is selected.
