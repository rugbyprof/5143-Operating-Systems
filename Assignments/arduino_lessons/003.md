# **Arduino Lesson 3 – Pushbutton-Controlled LED**

**Student Handout**

In this lesson, you will add a **pushbutton** to your Arduino circuit. The Arduino will read the button’s state and use it to control an LED. This introduces the concept of **digital inputs**.

---

# **1. Objective**

You will:

- Wire a pushbutton using a **pull-down resistor**.
- Read its state with `digitalRead()`.
- Use the button to start/stop the LED blink or simply turn it on/off.

---

# **2. Required Parts**

- Arduino Uno (or compatible)
- USB cable
- Breadboard
- 1 LED
- 1 Resistor for LED (220 Ω or 330 Ω)
- 1 Pushbutton (momentary, 4-pin)
- 1 Resistor: **10kΩ** (pull-down resistor)
- 6–8 jumper wires

You may reuse the LED circuit from Lesson 1.

---

# **3. Basic Concepts**

### **Pushbutton**

- A typical pushbutton has two internal switches:

  - The two pins on each side are **connected together**.
  - The switch connects **across** the gap when pressed.

### **Digital Input**

- Reads either:

  - **HIGH (5V)**
  - **LOW (0V)**

### **Pull-Down Resistor**

- Ensures the input reads **LOW** when the button is not pressed.
- When pressed, the button supplies **5V**, so the input reads **HIGH**.

---

# **4. Circuit Assembly**

## **4.1 Keep the LED circuit**

Use your LED + resistor + digital pin setup from previous lessons.

## **4.2 Add the Pushbutton**

Follow these steps carefully:

1. Insert the pushbutton so each pair of pins sits on opposite sides of the breadboard center gap.
2. Choose one leg pair to work with (either is fine).
3. Connect one pin of that pair to **5V**.
4. Connect the **other pin** of that pair to **digital pin 2** (recommended).
5. Add a **10kΩ resistor** from that same row (pin connected to D2) to **GND**.

### **How the button works in this setup:**

- **Not pressed:**

  - Input pin reads LOW because the 10kΩ resistor pulls it to GND.

- **Pressed:**

  - The switch connects the input pin to 5V.
  - The input reads HIGH.

**Double-check:**

- One button pin → 5V
- The opposite pin → D2 and → 10kΩ resistor → GND

1. Open the Arduino IDE.
2. Select the correct board and port.

# **6. Upload the Program**

### **6.1 Copy and paste this code:**

```cpp
const int LED_PIN = 13;   // LED from previous lessons
const int BUTTON_PIN = 2; // Pushbutton input

void setup() {
  pinMode(LED_PIN, OUTPUT);
  pinMode(BUTTON_PIN, INPUT);  // Using external pull-down resistor
}

void loop() {
  int buttonState = digitalRead(BUTTON_PIN);

  if (buttonState == HIGH) {
    digitalWrite(LED_PIN, HIGH);  // Button pressed → LED ON
  } else {
    digitalWrite(LED_PIN, LOW);   // Button not pressed → LED OFF
  }
}
```

# **7. Optional Variation: Button-Controlled Blink**

Replace the `loop()` with:

```cpp
void loop() {
  int buttonState = digitalRead(BUTTON_PIN);

  if (buttonState == HIGH) {
    digitalWrite(LED_PIN, HIGH);
    delay(200);
    digitalWrite(LED_PIN, LOW);
    delay(200);
  } else {
    digitalWrite(LED_PIN, LOW);
  }
}
```

---

# **8. Troubleshooting**

- **LED never responds**

  - Ensure the pull-down resistor goes from the **input pin row to GND**.
  - Confirm the button is placed across the breadboard center gap.

- **LED always ON**

  - Likely the input pin is floating; verify the pull-down resistor connection.

- **Button works only sometimes**

  - Check for loose connections.
  - Try rotating the button 90° (many students insert it the wrong way).
